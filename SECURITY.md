# Security policy

## Supported version

Security fixes are currently evaluated for the public `dev` release candidate,
JX General Dynamics `0.6.0rc1`. Earlier research snapshots are historical and
are not supported production releases.

## Reporting a vulnerability

Do not disclose an unpatched vulnerability, credential, private dataset, or
exploit detail in a public issue.

Use GitHub's private vulnerability-reporting or security-advisory interface for
this repository when it is available. If it is unavailable, contact the
repository owner through the owner's GitHub profile and request a private
reporting channel without including sensitive technical details publicly.

Include the affected commit, impacted component, minimal reproduction,
expected impact, and any known mitigation. Reports are handled on a best-effort
basis; no response-time or production-support guarantee is made.

## Scope

Security reports do not change the scientific status of the engine. The public
release remains `SCREENING_ONLY`, is not production-ready, and is not a
unified-multiphysics qualification.
