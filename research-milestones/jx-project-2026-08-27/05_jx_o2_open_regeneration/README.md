# JX-O2 open-regeneration protocol, local v1

This package freezes a design-only route for building a new, fully public,
physically matched M0/M1 model family. It does not reconstruct the private
`cluster_2` files and it may never be described as the authors' original run.
The required label for any later model is `CLUSTER2_LIKE_NEW_MODEL`.

The primary lane is a post-checkpoint intervention. An openly generated
compact-body-free cluster-history checkpoint at 300 Myr would be cloned within
each realization. M0 retains no additional body. M1 inserts one member of the
finite registered compact-body family at full mass, using a complete angular
state and an explicit barycentric transformation. The resulting estimand is
the effect of that intervention after 300 Myr; it is not a model of primordial
formation, capture, or survival before insertion.

The physical support contains all nine previously inspected 2026 literature
rows without pruning. Their equal weights are a new design assumption, not
published probabilities. The design uses 128 independent paired disk-and-
stellar histories and a predeclared, beacon-derived Latin-hypercube sample from
independent uniform angular nuisance distributions. The histories are
partitioned into four fixed 32-history convergence blocks; no disk draw or
stellar schedule is shared between histories. Every history uses one angle
triple across all nine rows, so angles and non-compact-body histories are common
controls rather than a favorable post-outcome selection. Published outcome
columns, prior JX engineering outcomes, and the retired historical candidate
cannot change membership or weights.

This is only a local content-hash lock and has no external timestamp. It
creates no checkpoint, full state, seed, deck, simulation, calibration,
observational statistic, or scientific result. Every one of the 31 JX-O2 G0
acceptance requirements remains scientifically unverified. A later externally
registered input-generation contract is required before generating even the
new cluster-like checkpoints, and a separate G1 contract is required after G0
before calibration or model comparison.

JX-O2 remains `BLOCKED`. No dynamics, GPU work, survey-adapter execution,
observed-data access, or Planet X claim is authorized by this package.
