# JX-XP2 V5 Offline Ceremony Review Package

This is a nonauthority, review-only package for a later user-operated Ubuntu host.
It is outside the accepted 149-document corpus and binds that corpus only through
previously reviewed fingerprints. It contains no key, signature, approval, ledger
event, fixed-policy instance, registration, runtime tree, result, receipt, activation,
compiled object, or executable grant.

The package is safe to inspect as text. Every current authorization field is false.
All external trust, path, runtime, clock, ledger, signer, and protection bindings are
UNBOUND. The C and Python sources are inert review blueprints and return or raise
without performing privileged work. A future ceremony must use separately reviewed,
externally authenticated binaries; changing a constant or deleting a guard is forbidden.

Read OFFLINE_CEREMONY_RUNBOOK.md first. The runbook begins with discovery and has
explicit stop conditions. Codex does not invoke sudo; the operator may later execute
reviewed steps manually on the offline Ubuntu host.
