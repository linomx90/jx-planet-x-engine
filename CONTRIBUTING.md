# Contributing

Contributions are welcome when they preserve the engine's falsification-first
scientific boundary.

For numerical or scientific changes:

1. State the physical or numerical question.
2. Lock acceptance gates before inspecting the final result.
3. Preserve configuration, code identity, raw output, checksums, and failures.
4. Add an independent numerical or analytic comparison for production claims.
5. Add or update tests and run the complete test suite.
6. Never relabel simulation output as astronomical measurement or detection.

Bug fixes that change a preserved numerical result should document the earlier
and corrected results and explain why the earlier artifact is superseded.
